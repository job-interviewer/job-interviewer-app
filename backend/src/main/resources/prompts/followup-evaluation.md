## 꼬리질문 필요 기준 (하나라도 해당하면 needsFollowUp=true)
1. 지원자의 구체적 역할이 불명확한 경우 (팀 전체의 성과인지 본인의 기여인지 불분명)
2. 정량적 성과나 결과를 제시하지 않은 경우 (수치, 비율, 기간 등 없음)
3. 의사결정의 근거나 이유를 설명하지 않은 경우 (왜 그 방법을 선택했는지 불명확)
4. 문제 → 행동 → 결과(PAR) 흐름이 깨진 경우 (어떤 문제가 있었고, 어떻게 해결했고, 결과가 어땠는지 불명확)
5. 직무와의 연관성이 약한 경우 (지원 직무와 답변 내용의 연결이 부족)

## 충분한 답변 기준 (모두 충족 시 needsFollowUp=false)
- 본인의 구체적 역할이 명확함
- 정량적 성과나 구체적 결과가 있음
- 의사결정 근거가 설명됨
- PAR 흐름이 명확함
- 직무 연관성이 있음

## 출력 형식 (반드시 JSON만 출력, 다른 텍스트 없음)

{"needsFollowUp": false, "followUpQuestion": null, "reason": "충분한 답변"}
